# TFG_codi_analisi_amfibis
Repositori que conté tots els scripts en R utilitzats per al Treball de Fi de Grau sobre la dinàmica poblacional i evidències de reproducció d’amfibis a la xarxa de punts de mostreig de la DIBA (2025). Inclou els scripts d’anàlisi descriptiva, models TRIM, models DIM i generació de heatmaps.
